集成指南

将工作区管理系统集成到您的现有页面中只需要几个简单步骤：

1. 引入必要文件

<!-- CSS 样式 -->
<link rel="stylesheet" href="modules/core/workspace-manager.css">

<!-- JavaScript 核心 -->
<script src="modules/core/WorkspaceManager.js"></script>
<script src="components/WorkspaceManagerUI.js"></script>

2. 初始化系统

// 系统会自动初始化，或者手动初始化：
document.addEventListener('DOMContentLoaded', () => {
    if (window.workspaceManager && window.workspaceManagerUI) {
        window.workspaceManagerUI.init();
    }
});

3. 打开新标签页

// 在您的页面链接中调用：
workspaceManager.openTab({
    id: 'monitor-realtime',
    title: '实时监控',
    url: '/monitor/realtime',
    icon: 'fas fa-desktop',
    group: 'monitor'
});

4. 创建自定义工作区

// 创建专门的工作区：
workspaceManager.createWorkspace('my-workspace', {
    name: '我的工作台',
    icon: 'fas fa-user',
    description: '个人定制工作区',
    defaultTabs: ['dashboard', 'monitor', 'reports']
});
